# Plans — Map of Content

Per-feature implementation plans written before coding. A plan names the goal, sketches the approach, calls out the tradeoffs, and lists the files likely to change.

Plans are not permanent. Once the feature ships, the plan can be archived or deleted — the decisions that came out of it belong in `decisions/`, the incidents that arose belong in `incidents/`, and the surviving architecture is documented in `architecture/`.
